## 🚀 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY_NAME.git
   cd YOUR_REPOSITORY_NAME
   ```

2. **Navigate to a specific day:**
   ```bash
   cd Day-01-Working-with-Variables
   ```

3. **Execute the project:**
   ```bash
   python main.py
   ```
